## 单篇文献目录

```text
论文文件名/
  原论文.pdf
  全文.md                    # 已完成时存在
  全文_校正版.md             # 有明确修复时存在
  正文/                      # 原始全文、版面JSON及图片
  化学解析/                  # 化学任务完成时存在
    分子.json
    反应.json
    反应_校正版.json          # 有明确修复时存在
    质量核对.md
    质量核对.json
    原文核对图/
  原始结果包/
  纠错记录.json              # 有明确修复时存在
  处理记录.json
  README.md
```

未完成论文只保留原文与处理状态，不生成占位结果。原文核对图为按页码、版面块匹配的整张原图／表，不是官方下载失败的单反应预览。

导出的来源路径与成果路径已转换为仓库内相对标识。文献和工具输出保留各自权利归属，本仓库不另授予原文再分发许可。
