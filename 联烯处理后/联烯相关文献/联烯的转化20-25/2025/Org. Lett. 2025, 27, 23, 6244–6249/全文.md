In recent years, sulfonyl fluorides have been recognized as privileged building blocks, which undergo sulfur(VI) fluoride exchange (SuFEx) click reactions.<sup>6</sup> Sulfuryl chlorofluoride $( \mathrm { F S O } _ { 2 } \mathrm { \bar { C } l } )$ , a useful solvent, has been successfully used as a dehydrating agent, an oxidant, and a source of $\mathrm { F } ^ { + } , \mathrm { F } { \mathrm { S O } _ { 2 } } ^ { + } ,$ or $\mathrm { C l ^ { + } } \overset { ? } { . }$ In 2020, Liao disclosed that $\mathrm { F S O } _ { 2 } \mathrm { C l }$ could act as a fluorosulfonyl radical $\left( \mathrm { F S O } _ { 2 } ^ { \bullet } \right)$ precursor for the synthesis of alkenyl sulfonyl fluorides.<sup>8</sup> After that, a few radical fluorosulfonylation strategies were developed using $\mathrm { F S O } _ { 2 } \mathrm { C l }$ under photochemical<sup>9</sup> or electrochemical<sup>10</sup> conditions. Recently, we demonstrated that $\mathrm { F S O } _ { 2 } \mathrm { C l }$ can simultaneously serve as a source of $\mathrm { F S O } _ { 2 } ^ { \bullet }$ and as an electron acceptor to form electron donor−acceptor (EDA) complexes in the fluorosulfonylation transformation.<sup>11</sup> However, $\mathrm { F S O } _ { 2 } \mathrm { C l }$ has been mainly used in a monofunctional fashion so far. We envisioned that it would be highly desirable and attractive to make full use of $\mathrm { F S O } _ { 2 } \mathrm { C l }$ as a multifunctional reagent to facilitate continuous reaction sequences.

Various synthetic methods have been developed for the introduction of the sulfonyl fluoride group,<sup>12</sup> particularly via radical fluorosulfonylation of alkenes or alkynes,<sup>13</sup> whereas the fluorosulfonylation of vinyl halides remains elusive (Scheme 1B). Herein, we report an unprecedented photochemical method to construct all-carbon tetrasubstituted olefins from allenols with $\mathrm { F S O } _ { 2 } \mathrm { C l }$ through double 1,2-carbon migration (Scheme 1C). In contrast to sulfonyl radicals, the fluorosulfonyl radical adds to the terminal carbon of allenes in our reaction. In this process, $\mathrm { F S O } _ { 2 } \mathrm { C l }$ plays a triple role: an efective Cl<sup>+</sup> synthon to facilitate semipinacol rearrangement to provide the vinyl chloride intermediate,<sup>14</sup> an electron acceptor to form EDA complexes, and a FSO <sup>•</sup> precursor to initiate radical carbonyl migration.<sup>15</sup> In addition, the generated sulfonyl fluorides possess an aldehyde, a tetrasubstituted alkene, and

We started of by investigating the reaction of allenol 1a with $\mathrm { F S O } _ { 2 } \mathrm { C l }$ under blue LED irradiation at ambient temperature for 2 h (Table 1). Originally, we thought silver salts might function as Lewis acids or chloride scavengers to promote the reaction, and several silver salts were examined using diethyl ether as the solvent (entries 1−4). Much to our delight, the $\mathrm { F S O } _ { 2 }$ -functionalized tetrasubstituted olefin 2a was isolated in 62% yield when the reaction was performed in the presence of ${ \mathrm { A g } } _ { 2 } { \mathrm { C O } } _ { 3 }$ (20 mol %) in diethyl ether (entry 4). Other solvents, such as THF, 2-Me-THF, CPME, and MTBE, delivered the desired product 2a in 0−10% yields (entries 5−7). Using 1,4- dioxane as the solvent, the desired product 2a was isolated in 50% yield (entry 8). Increasing or reducing the reaction concentration led to diminished yields (entries 9 and 10). Further optimization revealed that the mixed solvent 1,4- dioxane $/ \mathrm { E t } _ { 2 } \mathrm { O }$ (20/1) was found to be optimal (entry 11). A control experiment demonstrated that ${ \mathrm { A g } } _ { 2 } { \mathrm { C O } } _ { 3 }$ was unnecessary for this reaction (entry 12). No conversion of 1a was observed when the 1-fluorosulfonyl benzimidazolium salts developed by $\mathrm { L i a o } ^ { 1 6 }$ and $\mathrm { W a n g ^ { 1 7 } }$ independently were used as $\mathrm { F S O } _ { 2 }$ radical precursors, further demonstrating the unique role of $\mathrm { F S O } _ { 2 } \mathrm { C l }$ in our reaction.

Having identified suitable reaction conditions for tetrasubstituted olefin synthesis, the substrate scope of allenols was investigated (Scheme 2). The aryl ring was initially modulated with regard to electronic properties and the substitution pattern $\left( 2 \mathbf { a } \mathbf { - } 2 \mathbf { o } \right)$ . Electron-donating groups (tBu, Me, and $\mathsf { \bar { M } e O } )$ were well accommodated, providing desired products 2b−2e in moderate to good yields. Introducing a methyl group at the ortho position of the benzene ring led to a notable decrease in yield (2c) compared to para- and meta-substituted derivatives (2b, 2d, and 2e), presumably due to the steric efect. Halogens (Cl, Br, and I) and electron-withdrawing groups (CO H, CN, and SO Me) were tolerated, delivering desired sulfonyl fluorides 2f−2k. Other useful functional groups, including alkyne and boronic ester, were well-tolerated to aford 2l and $^ { 2 \mathbf { m } , }$ which are poised for further derivatization. Notably, the reactive benzyl alcohol (2n) and silyl ether (2o) also remained intact under our reaction conditions. Moreover, allenols bearing thiophene (2p), benzofuran (2q), and indole (2r) heterocycles are competent substrates for this cascade reaction. Subsequently, the presence of a methyl group on the terminal allene carbon was found to be not mandatory, since the method is applicable to ethyl- and phenylethyl-substituted allenols (2s and 2t). Delightedly, allenols from the naturally occurring aldehydes helicid and vanillin could be easily converted into sulfonyl fluorides 2u and ${ \bf 2 v , }$ respectively. In addition, NBS was used to form more reactive vinyl bromide intermediates through semipinacol rearrangement of 1p and 1u, thus providing $\mathbf { 2 p }$ and 2u in reasonable yields.

We initiated our mechanistic investigations by conducting a radical trapping experiment (Scheme 3A). When (1- cyclopropylvinyl)benzene 3 was added to the standard reaction of 1a with $\mathrm { F S O } _ { 2 } \mathrm { C l } _ { \cdot }$ , dihydronaphthalene 4 was isolated in 23% yield, thereby indicating the involvement of a reaction sequence of fluorosulfonyl radical addition/cyclopropyl ringopening/cyclization. Meanwhile, 1a was converted to intermediate 5a by the reaction with $\mathrm { F S O } _ { 2 } \mathrm { C l }$ via semipinacol rearrangement, and $4 ^ { \prime }$ or 2a was not obtained. In addition, when 1a-D was subjected to the standard conditions, 2a-D was isolated in 83% yield, strongly supporting the formyl migration is involved in the reaction (Scheme 3B). Interestingly, when the reaction of 1v and $\mathrm { F S O } _ { 2 } \mathrm { C l }$ was quenched after 40 min, vinyl chloride 5v could be isolated in 95% yield (Scheme 3C). Resubjecting $\pmb { 5 } \mathbf { v }$ to the standard conditions with additional 1- phenylethanol as the electron donor produced desired product 2v in 60% yield, suggesting that 5v is a plausible reaction intermediate. When the reaction 1v and $\mathrm { F S O } _ { 2 } \mathrm { C l }$ was monitored by <sup>1</sup>H NMR throughout its entire course, the conversion of allenol 1v to 5v and further to sulfonyl fluoride 2v as the final product was observed clearly (Scheme 3D).

Moreover, several spectroscopic studies were also performed to probe the generation of $\mathrm { F } \bar { \mathrm { S } } \mathrm { O } _ { 2 } ^ { \bullet }$ via EDA photoactivation (Scheme 3E). The ultraviolet−visible $\left( \mathrm { U V - v i s } \right)$ absorption experiments showed a significant red shift for the mixture of 1a and $\mathrm { F S O } _ { 2 } \mathrm { C l }$ (Scheme 3E(a)). The fluorescence quenching studies showed that allenol 1a could be eficiently quenched by $\mathrm { F S O } _ { 2 } \mathrm { C l }$ (Scheme 3E(b)). Based on the Benesi−Hildebrand method, an association constant $\left( K _ { \mathrm { E D A } } \right)$ of $2 . 4 \mathbf { M } ^ { - 1 }$ between 1a and $\mathrm { F S O } _ { 2 } \mathrm { C l }$ in $\mathrm { P h C F } _ { 3 }$ was obtained (Scheme $3 \mathrm { E } ( \mathrm { c } ) )$ Additionally, $\texttt { a } 1 : 1$ EDA complex between 1a and $\mathrm { F S O } _ { 2 } \mathrm { C l }$ was demonstrated by Job’s plot analysis (Scheme 3E(d)).

Based on these mechanistic studies, a plausible mechanism is outlined in Scheme 3F. Allenol 1 would first undergo semipinacol rearrangement with FSO Cl as the efective ${ \check { \mathrm { C l } } } ^ { + }$ synthon,<sup>18</sup> resulting in vinyl chloride 5. Meanwhile, visible light irradiation of the EDA complex, formed by the association of donor 1 with acceptor $\mathrm { F S } \bar { \mathrm { O } } _ { 2 } \mathrm { C l } ,$ generated the $\mathrm { F S O } _ { 2 }$ radical. Then, radical addition to the terminal olefin would occur, afording the alkyl radical I. Radical I underwent a diastereoselective cyclization to the aldehyde group, leading to alkoxy radical II. Subsequent fragmentation of the halogensubstituted cyclopropane II provided the desired sulfonyl fluoride 2 along with a chlorine radical. The resulting chlorine radical could then facilitate hydrogen atom transfer (HAT) with 1,4-dioxane to give α-oxo carbon-centered radical III, which engaged in halogen atom transfer (XAT) with $\mathrm { F S O } _ { 2 } \mathrm { C l }$ to deliver the $\mathrm { F S O } _ { 2 }$ radical.

We continued the studies by extending the reaction partners to other sources of radicals using a two-step procedure (Scheme 4). While halogen-promoted semipinacol rearrangement of allenols has been reported by $\dot { \mathbf { M } } \mathbf { a } , ^ { 1 8 }$ electrophilic halogenated reagents are restricted to $^ { \omega } \mathrm { B } \mathrm { \dot { r } } ^ { + \mathfrak { n } }$ and $^ { \omega } \mathrm { I } ^ { + \mathfrak { p } }$ . We found that $\mathrm { F S O } _ { 2 } \mathrm { C l }$ could function as an eficient $\mathrm { C l ^ { + } }$ reagent to facilitate the 1,2-aryl migration of allenols. Vinyl chloride 5a was isolated in 92% yield from the reaction of 1a with $\mathrm { F S O } _ { 2 } \mathrm { C l } .$ In contrast, the use of NCS and $S O _ { 2 } C \mathrm { l } _ { 2 }$ as halogenated reagents resulted in ineficient rearrangement, leading to the desired product 5a in 20% yield and a trace, respectively. Both sodium p-toluenesulfonate and phenylglyoxylic acid proved to be suitable radical precursors to react with ${ \mathfrak { s a } } ,$ furnishing the corresponding tetrasubstituted olefins 6a and 7a.

To demonstrate the synthetic utility of our methodology, we performed several synthetic transformations on product 2a (Scheme 5). Photosensitized alkene isomerization is a powerful synthetic strategy,<sup>20</sup> which ofers the opportunity for the stereodivergent synthesis of both E and Z isomers. Thus, we developed the isomerization conditions using riboflavin tetraacetate as the photosensitizer under 405 nm irradiation and converted the thermodynamically favored E-isomer 2a to less stable Z-isomer 8a. Next, 2a underwent $[ 4 + 2 ]$ annulation with acetylacetone or diethyl acetylenedicarboxylate, leading to tetrasubstituted arenes 9a or $\mathbf { 1 0 a } ,$ respectively. The aldehyde group within 2a was then condensed with TsNHNH to give N-Tosylhydrazone 11a, setting the stage for diverse follow-up functionalization. Treatment of 2a with TsNH in the presence of $\mathrm { F e C l } _ { 3 }$ resulted in aminoindene 12a through tandem condensation/Friedel−Crafts cyclization.<sup>21</sup> Finally, sulfonamide 13a and sulfonate 14a could be obtained in high yields from SuFEx reactions of 2a.

In conclusion, we have developed an unprecedented photochemical method to construct all-carbon tetrasubstituted olefins from allenols with $\mathrm { F S O } _ { 2 } \mathrm { C l } .$ The operationally simple protocol proceeds via a semipinacol rearrangement/radical 1,2- formyl migration cascade in an excellent regio- and stereoselective manner in the absence of any catalysts and additives. Mechanistic studies point out that $\mathrm { F S O } _ { 2 } \mathrm { C l }$ acts as an efective Cl<sup>+</sup> synthon to facilitate semipinacol rearrangement, an electron acceptor to form EDA complexes, and a $\mathrm { F S O } _ { 2 } ^ { \bullet }$ precursor to initiate radical 1,2-carbonyl migration. Furthermore, other types of radical precursors can be also applicable to this method, and the multifunctional tetrasubstituted olefins bestow diverse postsynthetic utilities.
