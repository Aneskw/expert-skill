Abstract A novel method for the preparation of 3-allenyl-4-methylenetetrahydrofurans via a Pd-catalyzed enyne cyclization reaction of propargyl 2-en-4-ynyl ethers under Suzuki coupling conditions is disclosed. The reaction proceeds via Pd activation of the terminal alkyne, cyclization, formation of the allenyl moiety, and reductive elimination, leading to the final product. This methodology offers several advantages, such as easy manipulation, mild reaction conditions, and easily accessible starting materials, providing a range of trisubstituted and 1,1- disubstituted allenyl(methylene)furan derivatives.

Key words allenes, furans, propargyl ethers, palladium, cyclization, Suzuki coupling

Allenyl heterocycles are useful synthetic intermediates due to the potential cyclization of heterocycles with the allenylic moiety to form polycyclic frameworks.<sup>1,2</sup> In addition, such allenyl heterocycles appear in natural products and pharmaceutical molecules.<sup>2</sup> Thus, development of synthetic methods for the construction of allenyl heterocycles and their applications have received much attention.<sup>1–3</sup>

Synthetic methodologies leading to allenyl compounds are well documented. Among them, Pd-catalyzed reaction of propargylic compounds I with nucleophilic organometallic or organoboron reagents to give the corresponding allene products is a known procedure (Scheme 1A).<sup>4</sup> In further applications, conjugated (Z)-2-en-4-ynes II behave similarly to provide the vinylallene products (Scheme 1B).<sup>5</sup>

By adopting this concept, we imagined that a 2-en-4-yl propargyl ether III with a terminal alkynyl group moiety could be useful to prepare allenyl(methylene)furans VI (Scheme 2). Presumably, activation of the terminal alkyne by Pd gives IV as the primary intermediate.<sup>6</sup> Hopefully, an intramolecular addition to the enyne moiety followed by isomerization and protonation at the terminal allenyl carbon would take place to provide vinylpalladium species V. Aryl group transfer from the boron reagent to the Pd center and then reductive elimination would deliver the target framework VI.

Compound 2a was characterized by NMR, mass spectrometry, and X-ray crystallography. HRMS (ESI-TOF) gave a signal at $[ \mathrm { M } + \mathrm { H } ] ^ { + } \mathrm { \Delta } m / z = 4 8 9 . 1 9 5 0 ,$ , consistent with the molecular formula of 2a. The coupling constants $J _ { ( \mathrm { H } 2 - \mathrm { H } 3 ) }$ for 2a and $\mathbf { 2 } \mathbf { a } ^ { \prime }$ are 8.8 and 7.0 Hz, respectively, which are consistent with a trans arrangement of these protons.<sup>8</sup> In addition, the $^ { 1 3 } \mathsf { C }$ NMR spectrum of 2a shows three signals at  207, 108, and 99 ppm, which are consistent with the signals of a trisubstituted allenyl moiety.<sup>9</sup> Nevertheless, X-ray crystallographic determination of 2a does confirm the structural details including the relative stereochemistry (Figure 1).<sup>10</sup>

Optimization of the reaction conditions for a better production of 2a was then studied (Table 1). The optimal conditions for this reaction are running the reaction of 1a with p-tolylboronic acid (1.1 equiv) with the use of $\mathrm { P d } _ { 2 } ( \mathsf { d b a } ) _ { 3 }$ (5 mol%) and $\mathrm { P C y } _ { 3 } { \cdot } \mathrm { H B F } _ { 4 }$ (40 mol%) as the catalyst in the presence of ${ \mathrm { N a } } _ { 2 } { \mathrm { C O } } _ { 3 }$ (0.8 equiv) in a mixed solvent of THF and MeOH at 65 $^ \circ C$ for 16 hours (entry 3). Due to easy manipulation, we chose to use $\mathrm { P C y _ { 3 } \cdot H B F _ { 4 } }$ as the ligand source instead of $\mathrm { P C y } _ { 3 } .$ By screening various amounts of ${ \ N a } _ { 2 } C 0 _ { 3 }$ (entries 1–4), we found that the use of 0.8 equivalent gave the best production of ${ \bf 2 } { \bf a } + { \bf 2 } { \bf a } ^ { \prime } .$ . Other bases, such as $\mathrm { K } _ { 2 } \mathrm { C O } _ { 3 }$ or ${ \mathrm { C s } } _ { 2 } { \mathrm { C O } } _ { 3 } ,$ did not provide the desired product at all (entries 5 and 6). Sodium hydroxide is another choice, but was not as good as ${ \ N a } _ { 2 } C 0 _ { 3 }$ (entry 7). Carrying out the reaction in THF/MeOH was found to be the best medium and other solvent systems gave poor results (entries 8–10). Among various phosphine ligands, tricyclohexylphosphine appears to be the most suitable for the reaction while other phosphine ligands impeded the catalysis (entries 11–15).

With the optimized conditions, reactions of various substituted groups R<sup>1</sup>, R<sup>2</sup>, and ${ \tt R } ^ { 3 }$ in 1 with various aryl- or alkylboronic acids were examined (Table 2). Reactants 1 with various substituents $\mathsf { R } ^ { 1 }$ reacted with phenylboronic acids smoothly under the catalytic conditions described above to give the allenylfuran products 2, except for 1d (R<sup>1</sup> = Me) (Table 2, entries 1–4). It appears that these substituents with different electronic natures affect the yield. When R<sup>1</sup> is a p-nitrophenyl group, the yield of 2b dropped to 55% (entry 2). Unfortunately, compound 1d with an alkyl substituent as $\mathsf { R } ^ { 1 }$ did not provide the desired product 2d at all (entry 4).

As for the boronic acids, phenylboronic acids with an electron-withdrawing or -donating substituent are suitable for the reaction, to give 2e and 2f in good yields (entries 5 and 6). However, reaction of 1a with butylboronic acid gave an unexpected product, 2g $\left( \mathbb { R } ^ { 4 } = \mathbb { H } \right)$ , indicating that the butyl group underwent -hydride elimination followed by reductive elimination to give the vinylidine moiety (entry 7). As for the $\mathsf { R } ^ { 2 }$ group, reactants 1 with a p-fluorophenyl or 3,5-dimethoxyphenyl substituent are suitable substrates, giving 2h and 2i in 61% and 87% yield, respectively (entries 8 and 9). The reactivity of three substrates with different $\mathbb { R } ^ { 3 }$ substituents was investigated. Both tolyl and butyl groups impede the formation of allenylfuran products (entries 10 and 12), whereas the reactant with $\mathbb { R } ^ { 3 }$ as a dichlorophenyl group provided the expected product 2k (entry 11). It appears that the nature of the $\mathbb { R } ^ { 3 }$ substituent affects the reaction significantly.

Finally, we investigated the activity of substrates with $\mathsf { R } ^ { 3 }$ as a trimethylsilyl (TMS) group. Compound 1p $( { \mathbb { R } } ^ { 1 } \ = \ p -$ $\mathrm { C l C _ { 6 } H _ { 4 } } , \mathrm { R } ^ { 2 } = p \mathrm { - } \mathrm { M e C _ { 6 } H _ { 4 } } , \mathrm { R } ^ { 3 } = \mathrm { T M S } )$ reacted with TolB(OH)<sub>2</sub> under the catalytic conditions described above to yield 3h in 78% yield (Scheme 5). The structure of 3h was characterized by spectroscopic methods. The shortage of a <sup>1</sup>H NMR signal for the TMS group clearly shows that desilylation took place during the cyclization, rendering the 1,1-disubstituted allene product 3h. Confirmation of this moiety came from the $^ { 1 3 } \mathsf { C }$ NMR shifts at  209, 104, and 84 ppm corresponding to the 1,1-disubstituted allenylic carbons and <sup>1</sup>H NMR shifts for the methylidene group.<sup>11</sup> In addition, the coupling constant of $J _ { \mathrm { ( H a - H b ) } } = 7 . 5$ Hz, similar to that for 2, suggests the trans relationship of the substituents on the furan ring. The success in obtaining 3h led us to prepare a series of this type of compound.

As shown in Table 3, substrates 1 with various substituted phenyl rings R<sup>1</sup> and R<sup>2</sup> underwent cyclization followed by formation of the allenyl group to render the desired products 3 in good yields, except for 1l $( { \tt R } ^ { 1 } = p { \mathrm { - } } { \tt M e C } _ { 6 } { \tt H } _ { 4 } , { \tt R } ^ { 2 } =$ $\scriptstyle { p \mathrm { - M e C } _ { 6 } \mathrm { H } _ { 4 } } )$ (Table 3, entry 3). It should be noted that 1q (Figure 2) with an internal alkynyl moiety did not undergo the expected cascade cyclization and decomposed during the reaction. In addition, this reaction did not proceed with compound 1r (Figure 2), with an allyl ether instead of propargyl ether, indicating the necessity of the alkynyl functionality.

A possible reaction pathway leading to 2 is illustrated in Scheme 6. Activation of the terminal alkyne of 1 by Pd(0) results in the formation of $\mathbf { I n t { - } 1 A } , ^ { 6 a }$ which then undergoes nucleophilic attack at the enyne moiety to yield the furan ring, Int-1B, where R<sup>2</sup> is seated at the pseudo-equatorial position to avoid steric strain. This orientation of R<sup>2</sup> readily renders the stereochemistry of the furan ring in the final product. The allenyl anion in Int-1B is able to accept a proton from a solvent molecule to give Int-1C. Transmetalation of the $\mathbb { R } ^ { 4 }$ group from $\mathsf { R } ^ { 4 } \mathsf { B } ( \mathrm { O H } ) _ { 2 }$ to Pd gives the intermediate Int-1D, which proceeds to undergo reductive elimination to yield the final product 2. For 1 with ${ \tt R } ^ { 3 }$ as a TMS substituent, desilylation might take place during the reaction in the formation of 3.

## Propargyl Ethers 1; General Procedure

In a 100-mL round-bottom flask was placed propargyl alcohol (1.01 g, 18 mmol) and $\mathrm { H } _ { 2 } S 0 _ { 4 }$ (0.48 mL, 9 mmol) in THF (10 mL). A solution of 1-en-4-yn-3-ol (3 mmol) in THF (15 mL) was then syringed into the flask with stirring at room temperature for 2 h. The reaction was quenched with sat. aq NaHCO and the mixture was extracted with ether (2 × 30 mL). The organic extracts were dried with MgSO and concentrated. The residue was chromatographed on a silica gel column (hexane/EtOAc, 19:1).
