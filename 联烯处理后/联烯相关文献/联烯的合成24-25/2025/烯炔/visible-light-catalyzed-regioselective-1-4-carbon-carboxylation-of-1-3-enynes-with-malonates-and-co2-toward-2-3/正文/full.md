Carbon dioxide (CO ) has emerged as an environmentally benign and renewable C1 feedstock in the synthesis of various value-added fine chemicals, owing to its natural abundance, cost-efectiveness, and low toxicity.<sup>10</sup> Among the diverse $\mathrm { C O } _ { 2 }$ transformations, the carboxylation reactions stand as one of the most convenient routes toward carboxylic acids.<sup>11</sup> In this field, carboxylation of unsaturated hydrocarbons with CO is most attractive, as it avoids the use of halides or moisture-sensitive organometallic reagents.<sup>12</sup> For example, Martin and coworkers,<sup>13</sup> Yu and co-workers,<sup>14</sup> Wu and co-workers,<sup>15</sup> Xi and co-workers,<sup>16</sup> and we<sup>17</sup> have developed a series of practical visible-light-driven carboxylation reactions of alkenes with $\mathrm { C O } _ { 2 } ,$ enabling the synthesis of diverse functionalized and structurally tunable aliphatic carboxylic acids through judicious selection of radical precursors. Furthermore, transition-metalcatalyzed or base-promoted difunctionalization of alkynes with $\mathrm { C O } _ { 2 }$ also represents an efective route to furnish diverse acrylic acids.<sup>18</sup> For example, Wu and co-workers reported a novel route for the synthesis of lactones or acrylic acids by iridium/ cobalt co-catalyzed hydro- or carbocarboxylation of alkynes with $\mathrm { C O } _ { 2 } . ^ { 1 9 }$ Additionally, Hong and Zhan independently reported the visible-light-promoted α-aminoalkyl- or phosphono-carboxylation of allenes with $\mathrm { C O } _ { 2 } ,$ leading to a series of $\beta _ { - }$ functionalized allylic carboxylic acids with good eficiency. 20 However, to the best of our knowledge, the carboxylation of $^ { 1 , 3 \cdot }$ -enynes with $\mathrm { C O } _ { 2 }$ remains unreported to date. In view of the high value of allenoic acids and in continuation of our interest in the $\mathrm { C O } _ { 2 }$ chemistry,<sup>21</sup> we envisioned the photocatalytic carboxylation of $^ { 1 , 3 \cdot }$ -enynes with malonates and $\mathrm { C O } _ { 2 } ,$ leading to allenoic acids in one step (Scheme 1d).

Initially, (3-methylbut-3-en-1-yn-1-yl)benzene 1a and dimethyl malonate 2a were employed as the model substrates to test our hypothesis. When the reaction of 1a with 2a and $\mathrm { C O } _ { 2 }$ in DMSO was conducted under irradiation of $2 \times 3$ W blue LEDs with PC1 as the catalyst and ${ \mathrm { C s } } _ { 2 } { \mathrm { C O } } _ { 3 }$ as the base. Delightedly, desired product 3aa could be isolated in 33% yield (Table 1, entry 1). Encouraged by this preliminary result, we screened other parameters. First, some common photocatalysts were tested, and the results indicated that PC4 gave the best result, afording 3aa in 80% yield (entries 1−4). Additionally, the solvent also showed an obvious efect. In DMF, 3aa was obtained in a 67% yield (entry 5). However, the reaction in NMP and MeCN aforded only 3aa in 45 and 50% yields, respectively (entries 6 and 7). Common bases were also screened. ${ \mathrm { N a } } _ { 2 } { \mathrm { C O } } _ { 3 } ,$ <sup>t</sup>BuOK, $\mathrm { K } _ { 2 } \mathrm { C O } _ { 3 } ,$ and ${ \mathrm { K } } _ { 3 } { \mathrm { P O } } _ { 4 }$ all resulted in inferior results than $\mathrm { C s } _ { 2 } \mathrm { C O } _ { 3 }$ (entries 8−11 vs 4). Furthermore, variation of the ratio of 1a/2a to 1:2 or 2:1 showed no improvement (entries 12 and 13 vs 4). Lowering the catalyst loading to 1 mol % resulted in a diminished yield (59%, entry 14). Finally, control experiments demonstrated that the catalyst, light, base, and $\bar { \mathrm { C O } } _ { 2 }$ were all essential to the success (entry 15).

Next, we investigated the reaction scope. First, a series of $^ { 1 , 3 \cdot }$ -enynes smoothly reacted with dimethyl malonate 2a and $\mathrm { C O } _ { 2 }$ under the optimized conditions, afording the desired products with good eficiency (Scheme 2). It was found that the electronic nature of the substituents at the para position of the phenyl ring had no obvious efect. Substrates bearing electron-donating groups, such as Me (1b), Et (1c), OMe (1e), <sup>t</sup>Bu (1e), and Ph (1f), and the one bearing electronwithdrawing groups, such as fluoro (1g), chloro (1h), bromo (1i), cyano (1j), and trifluoromethyl (1k), aforded 3ba−3ka in 73−80% yields. Additionally, those with m-methyl (1l), mchloro (1m), m-bromo (1n), o-methyl (1o), and o-chloro (1p) all worked well, leading to the desired products 3la−3pa in 58−81% yields, indicating that steric hindrance had no obvious efect. Furthermore, 2-naphthyl- (1q) and 2-thienyl- (1r) substituted 1,3-enynes also aforded the desired products 3qa and 3ra in 82 and 71% yields, respectively. It is noteworthy that substitutions at the 3 position had a profound influence, as no desired product 3sa could be detected when 1s was employed. Delightedly, 1,3-enynes substituted with 3-<sup>t</sup>Bu (1t), $3 { \mathrm { - } } \bar { \mathrm { C H } } _ { 2 } \mathrm { \bar { C H } } _ { 2 } \mathrm { \bar { O A c } } \ \mathrm { ( 1 u ) }$ , and cyclopropyl (1w) were employed, and the desired 3ta, 3ua, and 3wa could be isolated in 74, 65, and 80% yields, respectively. However, 3-phenyl analogous 1v could furnish only 3va in 25% yield. Particularly, cyclic 1,3- enynes 1x−1z were also good reaction candidates to deliver the desired products 3xa−3za. Additionally, when non-1-en-3- yn-2-ylbenzene 1A was employed, 3Aa could be obtained in 18% yield. Unfortunately, cinnamoyl-containing substrate 1B only resulted in a messy mixture with trace product detected. However, the one bearing an estrone motif 1C was amenable to the reaction conditions, furnishing 3Ca in 34% yield.

To demonstrate the utility of this method, a 1 mmol reaction of 1a with 2a and $\mathrm { C O } _ { 2 }$ was conducted under the slightly modified conditions, leading to the desired product 3aa in 77% yield (Scheme 4c). Then, further transformations of 3aa were also conducted. First, a CuCl-catalyzed annulation of 3aa proceeded smoothly, delivering the cycloaddition product 4 in 76% yield (Scheme 4d). Furthermore, a cyclization reaction of 3aa catalyzed by PdCl in the presence of allyl bromide aforded allyl furanone 5 in 70% yield (Scheme 4e). Treatment of 3aa with N-iodosuccinimide (NIS) furnished iodo-lactone 6 in 31% yield (Scheme 4f). Additionally, the amination of 3aa with methyl glycinate hydrochloride led to amide 7 in 53% yield (Scheme 4g). Alternatively, amination of 3aa with benzylamine, followed by the treatment of the obtained amide with NIS, aforded iodo-lactam 8 in 51% yield (Scheme 4h).

In conclusion, we have developed the first visible-lightpromoted 1,4-carbon/carboxylation of 1,3-enynes with malonates and $\mathrm { C O } _ { 2 } ,$ leading to a series of valuable tetrasubstituted 2,3-allenoic acids in good yields. This new methodology features good functional group tolerance, ease of scale-up, and facile transformations. Mechanistic investigations indicate that successive single-electron transfer (SSET) reduction is likely involved, with the allenoic anion serving as a key intermediate.
